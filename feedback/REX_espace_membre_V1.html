Comment l'utiliser ?

  • Côté gauche : capture pleine page de l'écran tel qu'affiché.
  • Côté droit : 4 questions UX (ce que ressent l'utilisatrice) + 4 questions UI (ce qu'elle voit) + notes libres.
  • Pour les parcours fonctionnels détaillés, se référer au guide utilisateur séparé.
  • Les captures de l'espace administrateur et membre sont peuplées avec des données factices.

Côté adhérente

Espace membre

Cette section présente l'expérience vécue par une adhérente du club, qu'elle soit nouvellement inscrite ou membre confirmée. Tableau de bord, parcours d'inscription aux ateliers, suivi de ses inscriptions, consultation du magazine, gestion de son compte : tout ce qu'elle voit après s'être connectée.

#1
Espace membre (rôles inscrit / membre)

Membre · Tableau de bord

/espace-membre

UX Parcours, perception, friction

  1. La salutation et le contenu sont-ils personnalisés ?
  2. Les 3 actions principales sont-elles à 1 clic ?
  3. L'empty state invite-t-il à découvrir le calendrier ?
  4. Quel élément donne envie de revenir chaque semaine ?

UI Composition, composants, accessibilité

  1. Le bloc « prochaine inscription » domine-t-il visuellement ?
  2. La sidebar est-elle cohérente avec l'espace admin ?
  3. Le rendu mobile reste-t-il pertinent ?
  4. Les microinteractions s'alignent-elles avec l'identité « cocooning » ?

Espace membre (rôles inscrit / membre)

Membre · Ateliers

/espace-membre/ateliers

UX Parcours, perception, friction

  1. Qu'apporte cette page de plus que /calendrier public ?
  2. L'inscription est-elle fluide sans re-saisie d'identité ?
  3. Les filtres utiles (thème, jour, animatrice) sont-ils présents ?
  4. Le statut « déjà inscrite » est-il visible immédiatement ?

UI Composition, composants, accessibilité

  1. Hiérarchie carte : photo, titre, date, places, CTA ?
  2. L'état « inscrite » combine-t-il couleur + texte ?
  3. L'empty state est-il chaleureux ?
  4. Disposition mobile en 1 colonne bien adaptée ?

#3
Espace membre (rôles inscrit / membre)

Membre · Mes inscriptions

/espace-membre/inscriptions

UX Parcours, perception, friction

  1. La séparation à venir / passées / annulées est-elle claire ?
  2. L'action principale (annuler, facture, avis) est-elle prioritaire ?
  3. Chaque inscription porte-t-elle ses infos clés sans cliquer ?
  4. L'avis est-il proposé uniquement après l'atelier ?

UI Composition, composants, accessibilité

  1. Les pastilles statut sont-elles visuellement distinctes ?
  2. Le statut paiement combine-t-il couleur + texte ?
  3. L'action « annuler » utilise-t-elle une couleur tertiaire ?
  4. La densité passé / à venir est-elle adaptée ?

#4
Espace membre (rôles inscrit / membre)

Membre · Magazine

/espace-membre/magazine

UX Parcours, perception, friction

  1. Le numéro courant est-il identifiable au premier regard ?
  2. Le confort de lecture (en ligne / téléchargement) est-il assuré ?
  3. Le sommaire est-il scannable ?
  4. Qu'est-ce qui donne envie de revenir chaque mois ?

UI Composition, composants, accessibilité

  1. La couverture a-t-elle un ratio cohérent et net ?
  2. La typographie de magazine (sérif élégante) est-elle utilisée ?
  3. Le bouton de téléchargement reste-t-il secondaire ?
  4. Le viewer mobile est-il performant ?

#5
Espace membre (rôles inscrit / membre)

Membre · Mon compte

/espace-membre/mon-compte

UX Parcours, perception, friction

  1. Les champs modifiables vs read-only sont-ils explicites ?
  2. La sécurité (ancien mot de passe demandé) est-elle assurée ?
  3. La suppression du compte a-t-elle un parcours clair ?
  4. Les préférences de communication sont-elles transparentes ?

UI Composition, composants, accessibilité

  1. Sections clairement séparées (info, sécurité, préférences) ?
  2. Les champs read-only sont-ils marqués (cadenas, fond grisé) ?
  3. L'action destructrice est-elle isolée et tertiaire ?
  4. Le toast de confirmation explicite-t-il ce qui est enregistré ?
