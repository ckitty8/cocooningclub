# Plan Alimentaire · Madame Protéine

Application React standalone — plan alimentaire personnalisé 7 jours, style Madame Protéine.

## Démarrer

```bash
npm install
npm run dev
```

## Technologies

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 3 — design Playfair Display + DM Sans (identique à Cocooning Club)
- Recharts — graphique calories par jour
- jsPDF — export PDF A4 imprimable

## Fonctionnalités

1. **Profil** — prénom, poids actuel/objectif, taille, date objectif, activité, allergies
2. **Plan 7 jours** — 6 repas/jour avec règles d'alternance céréale/légumineuse
3. **Récapitulatif** — tableau semaine, graphique, bilan calorique + PDF A4
