# Illustrations du site

Illustrations vectorielles **originales**, dessinées pour le club (formes simples, palette de la charte). Aucun droit à
vérifier, aucune attribution à afficher, nettes à toutes les tailles. Elles remplacent des images dont l'origine n'était pas connue.

| Fichier | Où |
|---|---|
| `hero-atelier.svg` | Calendrier, accueil (appel à rejoindre le club), pages de connexion |
| `papotages.svg`, `creatif.svg`, `business.svg` | Accueil, cartes des trois espaces |
| `histoire-groupe.svg`, `histoire-carnet.svg`, `histoire-neon.svg` | Page « Notre histoire » |
| `polaroid-rencontres.svg`, `polaroid-idees.svg`, `polaroid-aventure.svg` | Page « Notre histoire », polaroïds |

Elles sont générées par `scripts/generate-illustrations.py` (modifier le script, puis le relancer). L'image de partage
`public/og-image.jpg` reprend le même style pour sa moitié gauche.

Pour remplacer une illustration par une vraie photo : mettre le fichier (WebP, ~1200 px) à côté et changer l'import dans la page.
Photos libres de droits : Unsplash, Pexels ou Pixabay (usage commercial permis, attribution non obligatoire) ; noter la source et la
licence dans ce fichier.
